# ITQAN ADVISORY LTD — GitHub Pages Website

Premium navy-and-gold responsive website. The homepage now prominently displays **ITQAN ADVISORY LTD** and **ACCA Certified Chartered Accountant & Tax Advisor** in the header, hero and About section.

## Publish on GitHub Pages
1. Upload `index.html`, `styles.css`, `script.js`, and `.nojekyll` to the root of your GitHub repository.
2. Go to Settings > Pages > Build and deployment > Deploy from a branch.
3. Choose `main` and `/ (root)`, then save.

The contact form opens the visitor's email application; it does not send directly from the website. Pricing is reserved for future publication and currently hidden.

**Before publication:** Verify the exact ACCA designation and practice status with ACCA. The label requested by the owner is included as supplied and is not independently verified. Statutory audit services may only be offered by appropriately registered audit firms. Add the firm's required regulatory, privacy and company disclosures before launch.
