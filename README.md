# itqanadvisory

**ITQAN Advisory Ltd - Official Website**

A responsive static website for ITQAN Advisory Ltd.

## Project Structure
- `index.html` - Complete responsive single-page website
- `styles.css` - Design styling (navy & gold palette) and responsive mobile layout
- `script.js` - Mobile navigation and client-side contact enquiry handler
- `README.txt` - Deployment and pre-launch compliance notes

## Preview
Open `index.html` in any modern web browser or deploy directly to GitHub Pages, Netlify, Vercel, or traditional static web hosting.
